# Financial Tracker

A full‑stack web app to manage personal finances – track income and expenses, view spending by category, compare monthly totals, and switch between light/dark themes.

## Features
- User registration & login (JWT authentication)
- Add, edit, delete transactions
- Categorise expenses/income
- Dashboard with pie chart (spending vs income) and monthly bar chart
- Dark / light mode toggle

## Tech Stack
- **Frontend:** React (Vite), Chart.js, Axios, React Router
- **Backend:** Django, Django REST Framework, Simple JWT, MySQL
- **Styling:** CSS custom properties (theming)
